# heaprule

Heap digests and rule fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/heaprule/

## Install / run

```bash
git clone https://github.com/theworker02/heaprule.git
cd heaprule
node src/cli.js
node --test
```
